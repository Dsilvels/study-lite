
# StudyLite 💜

## About My Project
StudyLite is a simple website that helps students keep track of their school assignments. I wanted to create something that makes staying organized easier and completing assignments a little more fun.

## Features
Students will be able to:
- Add assignments and due dates
- View their assignments
- Mark assignments as completed
- Earn 10 XP for completing assignments
- See their total XP

## Tools I Will Use
- HTML and CSS - To design the website
- Python and Flask - To make the website work
- SQLite - To save assignments and points
- GitHub - To save my code
- Docker - To run my application
- GitHub Actions - To automatically test and deploy my code
- Google Cloud - To put my website online
- Jira - To organize my project
